# Marketing Video Agent — عقد الوكيل

**المفتاح:** `marketing-video-agent` · **Tier:** `CORE_SPECIALIST` · **القسم:** `growth`
**الحالة:** مُعلن بعقد كامل، **غير قابل للتنفيذ** (`executable: false`)

## 1. المهمة

تحويل هدف تسويقي إلى **خطة فيديو كاملة** — جمهور، رسالة، سكربت، ستوري بورد، قائمة أصول،
ونسخ لكل منصة — **دون إنتاج ولا نشر**. الإنتاج والنشر خطوتان منفصلتان بموافقة بشرية.

## 2. القدرات المعلنة

| القدرة | الوصف | موافقة؟ |
| --- | --- | --- |
| `plan_video` | خطة فيديو من هدف وجمهور | لا |
| `write_script` | كتابة السكربت والنصوص على الشاشة | لا |
| `build_storyboard` | تقسيم المشاهد والصور والمؤثرات الصوتية | لا |
| `prepare_delivery` | تجهيز النسخ والبيانات الوصفية للتسليم | لا |
| `render_video` | رندر الفيديو بأداة إنتاج معتمدة | **نعم** |
| `publish_video` | نشر الفيديو على منصة خارجية | **نعم** |

`video.publish` و`video.render_paid` مضافتان إلى `SENSITIVE_ACTIONS`: تُرفضان دائماً بلا موافقة
بشرية، أيّاً كان الوكيل.

## 3. البيانات والأدوات

`allowedTools` **إعلانية فقط** ولا تُمنح أي وصول على هذا الفرع (لا Tool Gateway مربوط):

- `marketing.read_catalogue_owned`, `marketing.read_brand_assets`, `video.read_assets_owned`
- `video.plan_storyboard`, `video.render_approved`, `video.publish_approved`

`scope: 'own'` — كتالوج المستدعي فقط، لا تجميعات منصة.

## 4. الحدود

| الحد | القيمة |
| --- | --- |
| تكلفة التشغيل | `maxCostUsdPerRun: 2` |
| عدد المشاهد | `maxScenesPerVideo: 12` |
| المدة | `maxDurationSeconds: 120` (وسياسة المنصة 35–120ث) |
| الصلاحيات | `ai:use` فقط — لا صلاحية جديدة |

## 5. لماذا لا يوجد منفّذ؟

القدرة الحقيقية موجودة في `lib/media/*` وتُشغَّل عبر `modules/media/routes.ts` (رندر MP4 فعلي،
تخزين خاص، روابط موقّعة، تحقق مدة من البايتات، ومحاسبة عبر `MARKETING_VIDEO`).

ربطها كمنفّذ وكيل يفتح قرارات لم تُعتمد بعد:

1. **سقف التكلفة**: هل يُحمَّل الرندر على ميزانية الوكيل أم على حساب المالك؟
2. **ملكية الأصول**: الأصول تُنسب للمنتج/البائع — من يملك نسخة الوكيل؟
3. **النشر**: أي منصة، بأي حساب، ومن يوافق؟ (اليوم: لا نشر خارجي إطلاقاً)
4. **الفصل عن Marketing Agent**: `marketing-agent` يبقى تخطيط حملات وقنوات؛ الفيديو هوية مستقلة.

هذه مسجّلة كـ`DECISION REQUIRED` في AD-049، والوضع الحالي **fail-closed**:
`agentRunRefusal` يرفض أي مهمة لهذا الوكيل، والمخطِّط يرفض أي خطة تحتويه.
