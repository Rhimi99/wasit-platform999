### لماذا الحزمة المسجَّلة تكفي الآن

نصّ الفيديو التونسي صار **ثابتًا بالكامل** (المنتج والسوم والعلامة تظهر على الشاشة، لا تُنطق).
النتيجة: كل الفيديوهات التونسية تحتاج **6 أسطر / 60 كلمة** فقط، تغطيها جلسة استوديو واحدة:

```bash
npm run voices:brief -w @wasit/server   # يكتب artifacts/voice-packs/ar-TN/{brief.md,lines.json}
```

## 3. المسار المُنفَّذ: حزمة صوت مسجَّلة (Voice Pack)

- `VOICE_PACK_DIR` (أو `vendor/voices/`) → `<root>/ar-TN/manifest.json` + ملفات WAV.
- المطابقة بـ`sha256` على السطر بعد تطبيع المسافات، فلا يفشل التسجيل بسبب فرق تشكيل في المسافات.
- **حرس الترخيص** في `lib/media/voice-pack.ts`، يُرفض أي ملف عند غياب:
  - `license.commercialUse: true` (وإلا: «not licensed for commercial use»)
  - `license.holder` و`license.terms` (جهة الإذن ومرجعه)
  - `consent.reference` (إقرار موقَّع)
  - `dialectNative: true` للهجة `ar-TN` (يمنع تسمية تسجيل فصحى «تونسيًا»)
  - صلاحية غير منتهية، وملفات موجودة، وبلا سطر مكرَّر.
- الحزمة المسجَّلة **تسبق** أي صوت صناعي عند وجودها (`resolveVoice`).
- سطر غير مسجَّل ⇒ خطأ صريح يذكر السطر ويوجّه إلى `voices:brief`؛ لا سكوت ولا بديل فصحى.

### ما أُثبت فعليًا

- الحزمة التجريبية المرفقة في `tests/fixtures/voice-pack/ar-TN` هي **Piper فصحى** ومعلَّمة
  `dialectNative: false` ⇒ رفضها المحمّل كما يجب (اختبار صريح).
- نسخة اختبارية منها بـ`dialectNative: true` (إثبات سباكة فقط، لا ادعاء لهجة): أنتجت فيديو
  **35.0 ثانية**، 720×1280، h264 + AAC 44.1kHz، **-15.7 LUFS**، بموسيقى وترجمة.
- أي أن المسار جاهز: بمجرد وضع تسجيل تونسي مرخَّص في المجلد، يمر الفيديو من البوابة ويُسلَّم.

## 5. ما يلزم من المدير العام

1. **اختيار المسار**: (أ) تسجيل بشري لحزمة الـ6 أسطر — الأنسب والأرخص تشغيليًا؛ (ب) Azure `ar-TN`
   للتوسع الفوري بكل النصوص (يحتاج اشتراكًا واختبار سماع)؛ (ج) الاثنان معًا (بشري للعلامة، Azure للحجم).
2. **اعتماد ميزانية** إن اختير Azure أو الاستوديو.
3. **تحديد من يوقّع عقد التنازل** بصيغته النهائية (نطاق عالمي، مدة، مقابل، حق إعادة الاستخدام داخل المنصة).
4. **مراجعة بشرية تونسية** لأي صوت قبل اعتماد الجودة التجارية: النطق، الوضوح، التزامن، مستوى الصوت.

## 6. حالة اللهجة التونسية

**مفتوحة.** لا صوت تونسي مرخَّص مُثبت بعد، و`ar-TN` يبقى محجوبًا في البوابة (`audio.voiceover`
أو `audio.dialect_native`) حتى يصل تسجيل موقَّع أو اعتماد Azure مع اختبار سماع.
