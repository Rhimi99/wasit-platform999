## 6. القسم المالي الخاص

### 6.1 احتساب عمولة WASIT (4%)
```
قيمة الصفقة (مثال)              = 1000
  عمولة البائع (2%)             =   20
  عمولة المشتري (2%)            =   20
  إجمالي عمولة WASIT (4%)       =   40
  صافي مستحقّ البائع            =  980
  ما يدفعه المشتري              = 1020
```
- **مصدر النسبة:** سياسة `BASE` في قاعدة البيانات (`commission_policies`: `rate=0.04`, `sellerRate=0.02`, `buyerRate=0.02`) — **غير مضمّنة في الكود** (seed).
- **المحرّك يفشل مغلقاً:** إن لم تطابق سياسة → `COMMISSION_POLICY_MISSING` (لا نسبة افتراضية).
- **قابل للتخصيص:** حسب الحساب/النوع B2B-B2C/البلد/العملة/القطاع/الحجم.

### 6.2 رسوم مزوّد الدفع — **منفصلة عن العمولة**
- تُحتسب من `payment_fee_policies` (افتراضي 2% لبيئة التطوير).
- مطلوب شفافية: **من يدفع (Payer) ولمن (Beneficiary)** لكل حركة.

### 6.3 طرق الدفع الموجودة

| الطريقة | الحالة |
| --- | --- |
| بطاقة (Card) | محوّل موجود |
| محفظة موبايل (D17 / FLOUCI_WALLET) | محوّل موجود |
| Flouci | محوّل `flouci.ts` |
| ClicToPay | محوّل `clictopay.ts` (لا يدعم Refund) |
| Manual (يدوي/offline) | `manual` — DEMO-only |
| Open-Checkout (عام) | عقد HTTP عام |

### 6.4 الفرق بين الدفع التجريبي والحقيقي

| البند | الدفع التجريبي (الآن) | الدفع الحقيقي (مطلوب) |
| --- | --- | --- |
| المزوّد | `manual` / sandbox | مزوّد مرخّص بمفاتيح إنتاجية |
| المفاتيح | لا توجد | مفاتيح إنتاجية + Sandbox |
| Split | غير مؤكَّد | مؤكَّد كتابياً |
| الاسترداد | يدعم داخلياً | يعتمد على دعم المزوّد (ClicToPay لا يدعم) |
| الإثبات | اختبارات بلا DB | Webhook حيّ + تسوية بنكية |

### 6.5 دورة Payment → Ledger → Settlement → Payout

| الحلقة | الوظيفة | الحالة |
| --- | --- | --- |
| Payment | نية + Webhook HMAC + إعادة تحقق | 🔵 منفّذ (مزوّد تجريبي) |
| Ledger | تسجيل الحركة (لا محفظة/لا رصيد) | 🔵 منفّذ |
| Settlement | تأكيد تحرّك المال بدليل | 🔵 منفّذ (يحتاج دليل مزوّد) |
| Payout | صافي للبائع | 🔵 منفّذ (يحتاج مزوّد) |
| Reconciliation | مطابقة ثلاثية | 🔵 منفّذ |

### 6.6 ما يعمل / ما يُحاكى / ما يحتاج اعتماداً

- **يعمل فعلياً:** العمولة، الدفتر، التسوية، المستحقات، المطابقة، الاسترداد (محرّك)، الضرائب، الإيرادات، الاشتراكات.
- **يُحاكى (DEMO):** الدفع اليدوي، الدفع بلا مزوّد حقيقي، الرسوم.
- **يحتاج مزوّداً/عقداً/اعتماداً:** مزوّد دفع حقيقي، تأكيد Split، حساب تسوية/بنكي، مزوّد Refund.

### 6.7 حدود WASIT (وسيط فقط — قرارات مجمّدة)
- ❌ لا محافظ · ❌ لا أرصدة مستخدمين · ❌ لا احتفاظ بأموال العملاء/التجار · ❌ لا نقل/تسليم منتجات.
- ✅ `مدفوع ≠ مسوّى` · ✅ كل كتابة مال عبر مسار واحد مُدقّق · ✅ العمولة قرار مالك.
