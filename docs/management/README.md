# الدليل الإداري لمهام وصلاحيات المدير العام والمدير

وثيقة إدارية رسمية تصف — اعتماداً على الكود الفعلي فقط — ما يستطيع كل من
`SUPER_ADMIN` و`ADMIN` تنفيذه في منصة WASIT BUSINESS GLOBAL، وما يقتصر على
القراءة، وما هو موجود في الـBackend دون واجهة، وما لا وجود له أصلاً.

## الملفات

| الملف | الوصف |
| --- | --- |
| `WASIT-Admin-Permissions-Guide-AR.pdf` | الدليل النهائي (A4، RTL، غلاف + فهرس + ترقيم صفحات) |
| `build-pdf.mjs` | مولّد الدليل: يبني `cover.html` و`guide.html` ثم يحوّلهما إلى PDF عبر Chromium |
| `cover.html` / `guide.html` | وسيطا العرض (مصدر الـPDF نفسه) |
| `assets/fonts/` | خطوط عربية مفتوحة (IBM Plex Sans Arabic، Amiri) بترخيص OFL |

## إعادة التوليد

```bash
node docs/management/build-pdf.mjs
```

يحتاج `chromium` و`pypdf` فقط. المولّد **لا يقرأ من التطبيق ولا يكتب في قاعدة
البيانات**: مضمون الدليل مكتوب صراحةً داخل `build-pdf.mjs` ومستخرج يدوياً من
الكود عند الإصدار المسجَّل في الغلاف.

## إصدار المحتوى

الغلاف يذكر الفرع و`commit` اللذين استُخرج منهما كل صف. أي تغيير في RBAC أو
المسارات بعد ذلك الإصدار يتطلّب تحديث `build-pdf.mjs` وإعادة التوليد.

**الإصدار المسجَّل في الغلاف:** `master` @ `e43dee4` (`e43dee4017d2848e37d03d13025a33890adb483f`).
هذا **لقطة (snapshot) مقصودة** من الأساس، وصفوفه صحيحة **على ذلك الإصدار فقط**.

## الفجوة مع الكود الحالي (تحديث DOC-ALIGN-01 — 2026-11-04)

بعد `e43dee4` أُنجزت إصلاحات **PERM-01B/C** (غير مُودَعة) لم تنعكس في هذه اللقطة.
الصفوف التالية في الدليل **صارت متجاوزة** ويجب تحديثها عند إعادة التوليد:

| موضع الدليل | النص في اللقطة (e43dee4) | الكود الحالي | مصدر التغيير |
| --- | --- | --- | --- |
| المخزون (القسم 5.3، السطر ~87) | «`inventory:*` محصورة بـSUPER_ADMIN» | ADMIN يملك **قراءة** فقط (`inventory:read` + `inventory:read:all`)؛ الكتابة للبائعين وSUPER_ADMIN | PERM-01B (`rbac.ts`) |
| المخزون (القسم 6، السطر ~294) | «`inventory:*` لـSUPER فقط» | ADMIN يقرأ عبر كل البائعين، ولا يكتب | PERM-01B |
| عدد الصلاحيات (السطر ~296) | «79 / 110» | **81 / 111** (ADMIN / SUPER_ADMIN) | PERM-01B + عدّ مصحّح |
| خلاصة الصلاحيات (السطر ~473) | «الفارق 110 مقابل 79» | «111 مقابل 81» | كما أعلاه |
| التقارير (السطر ~154) | `/api/admin/analytics/reports` | ✅ **لا يزال صحيحاً** | — |
| الضريبة (السطر ~197) | `GET /api/admin/tax/*` | ✅ المسار صحيح؛ الحارس صار `admin:policies` (لم يكن الدليل يذكر الحارس) | PERM-01C |

**إضافة غير مغطّاة في اللقطة:** حراسة مسارات الكيانات (`POST /api/{suppliers,merchants,companies}`)
بصلاحية RBAC عبر `requireRoleOrPermission` (PERM-01C) — يخصّ البائعين لا ADMIN/SUPER_ADMIN،
فقد يكون خارج نطاق هذا الدليل الإداري.

**حالة إعادة التوليد في هذه البيئة:** `chromium` متاح، لكن **`pypdf` غير مثبَّت**؛ لذلك
**لم يُعَد توليد** الـPDF ولا `cover.html`/`guide.html` (ولن تُثبَّت حزم نظام في مهمة توثيقية).

## حدود الدليل

- وجود صلاحية في RBAC لا يعني وجود واجهة أو وظيفة مكتملة؛ لذلك يميّز الدليل
  بين «منفَّذ» و«Backend فقط» و«ناقص» و«غير موجود» و«محظور».
- المعيار المتَّبع: وجود الحارس في المسار + وجود المسار في `app.ts` + وجود سطح
  في لوحة الإدارة.
