# 7. سياسة الاحتفاظ بالنسخ الاحتياطية

## الهدف

نسخ كافية للاستعادة، بلا استنزاف القرص، وبلا حذف غير مقصود.

## الافتراضيات

| المعامل | القيمة | المصدر |
| --- | --- | --- |
| عدد النسخ المحفوظة | 10 | `--keep` أو `SESSION_BUNDLE_KEEP` |
| أقل عمر قبل الحذف | 7 أيام | `SESSION_BUNDLE_MIN_AGE_DAYS` |
| الحذف التلقائي | **معطّل** | يتطلب `--prune` صريحًا |

## كيف يعمل `--prune`

1. يجمع `wasit-*.bundle` في مجلد الوجهة فقط.
2. يرتّبها من الأحدث.
3. يتخطى أحدث `N`.
4. **يتخطى أي نسخة عمرها أقل من 7 أيام** حتى لو تجاوزت `N`.
5. يحذف الباقي فقط.

لا يلمس: `manifest.tsv`، ولا أي ملف لا يطابق `wasit-*.bundle`، ولا أي مجلد آخر.

## إيقاع مقترح

| التوقيت | الأمر |
| --- | --- |
| بداية كل يوم عمل | `session backup --label daily` |
| قبل ترحيل/إعادة هيكلة | `session backup --label before-<task>` |
| أسبوعيًا | نسخ أحدث bundle إلى تخزين خارج الحاوية |
| شهريًا | `session backup --prune --keep 10` بعد التأكد من النسخ الخارجية |
| ربع سنوي | drill استعادة من أقدم bundle محتفظ به |

## التحقق قبل الحذف

```bash
# 1) ما الذي سيُحذف؟
find backups/git -name 'wasit-*.bundle' -printf '%TY-%Tm-%Td %p\n' | sort

# 2) هل أحدث نسخة سليمة؟
sha256sum -c <(awk -F'\t' 'NR>1{print $2"  backups/git/"$7}' backups/git/manifest.tsv | tail -1)
```

## قيود

- bundle يحفظ **تاريخ Git** فقط. قواعد البيانات والوسائط لها مسارات منفصلة
  (`scripts/backup-db.sh`).
- لا تُحذف نسخة إن لم توجد نسخة أحدث سليمة منها.
- عند الشك: لا `--prune`. المساحة أرخص من فقدان تاريخ.
