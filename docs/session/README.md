# حفظ العمل بين الجلسات — دليل سريع

> هذا المجلد هو المرجع الوحيد لاستمرارية العمل في WASIT. أي وكيل جديد يبدأ من هنا،
> لا من ذاكرة محادثة سابقة.

## القاعدة الأساسية

**GitHub هو النسخة الدائمة. الحاوية والمساحة المحلية نسختان مؤقتتان.**

أي عمل ليس في commit مدفوع على `origin` = عمل مُعرَّض للضياع.

## الأوامر الخمسة

```bash
./scripts/session/session start          # قبل أي عمل: هل المساحة آمنة؟
./scripts/session/session checkpoint -m "…"   # بعد كل جزء مكتمل ومُختبَر
./scripts/session/session close          # قبل إنهاء الجلسة: هل كل شيء مدفوع؟
./scripts/session/session status         # صورة كاملة: محلي/بعيد/نسخ
./scripts/session/session backup         # Git bundle + SHA-256 + manifest
./scripts/session/session recovery --target <مسار جديد>   # بعد فقدان الحاوية
```

## ضوابط غير قابلة للتفاوض

- لا `git push --force`، لا `git reset`، لا `git clean`، لا حذف فروع أو نسخ.
- لا أسرار في أي commit (الـcheckpoint يرفض تلقائيًا).
- لا تعتبر commit محليًا نسخة احتياطية.
- عند أي تعارض أو غموض: احمِ العمل (bundle + checkpoint) وتوقّف.
