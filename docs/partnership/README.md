## المحتوى

### الملف الكامل (Dossier)
يغطي: ما هي WASIT · المشكلة التي تحلها · كيف تعمل · المستخدمون المستهدفون · نموذج الإيرادات · السوق · خريطة الوظائف الكاملة · طبقة الذكاء الاصطناعي (11 وكيلًا + Copilot) · البنية التقنية · الحالة الحالية بالتفصيل · ما تم التحقق منه · ما يزال ناقصًا (تقنيًا/تجاريًا/قانونيًا/تشغيليًا) · لماذا الشراكة · أنواع الشراكة · ما تقدّمه WASIT · ما نبحث عنه · فلسفة الشراكة · خارطة الطريق · المخاطر.

**ملحقان إضافيان:** جدول Fact Check من 21 ادعاءً بدليلها، وسجل الأدلة (نتائج الاختبارات وتوزيع دفتر الحسابات).

### العرض المختصر (Presentation)
نسخة مركّزة للعرض الأول على الشريك، بنفس المادة الجوهرية بلا ملاحق.

## المبادئ المتبعة في الإعداد

- **لا مبالغة ولا اختلاق.** كل تصنيف حالة مبنيّ على دليل داخل المشروع أو نتيجة اختبار أُعيد تشغيلها.
- **لا أرقام سوقية ولا توقعات GMV** — المشروع لا يحتوي على دراسة سوق أو نموذج مالي مُعتمد، فلم تُدرج أي أرقام من هذا النوع.
- **الفجوات معلنة بوضوح:** الوثائق القانونية غير موجودة، KYC/KYB وAML بلا كود مخصص، مزوّدو الدفع وAI الإنتاجيون يحتاجون تكوينًا، وWASIT AI Copilot مواصفة فقط (غير منفَّذ).
- **لا شروط مالية محددة:** لم تُذكر أي نسب ملكية أو حصص؛ هيكل الشراكة متروك للنقاش.
- **توثيق فقط:** لم يُعدَّل أي كود، ولم تُنشأ أي commit، ولم يُنفَّذ أي reset/drop لقاعدة البيانات.

## إعادة البناء

مصادر Markdown في هذا المجلد هي المصدر الواحد للصيغ الثلاث:

```bash
python3 .partner-docs/build_html.py      # Markdown → HTML
node    .partner-docs/render_pdf.mjs     # HTML → PDF
python3 .partner-docs/build_office.py    # Markdown → DOCX + PPTX
```

تستخدم عملية البناء خط **Noto Sans Arabic** المُرفق في المشروع
(`packages/server/assets/fonts/`)، لذا يظهر النص العربي بصورته الصحيحة بلا رموز ناقصة.
